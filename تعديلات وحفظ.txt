لقد قمت ببعض التغيرات بالكود واريد الرفع والحفظ

ممتاز! لرفع وحفظ التعديلات التي أجريتها على الكود وتحديث موقعك على جيت هب، اتبع هذه الخطوات البسيطة:

الطريقة الأولى: المباشرة من موقع جيت هب (إذا كنت تعدل الملفات من المتصفح)
إذا كنت تجري التعديلات من داخل صفحة المستودع على جيت هب، انزل إلى أسفل الصفحة حيث ستجد مربع Commit changes (حفظ التعديلات).

اكتب وصفاً مختصراً للتعديل في خانة العنوان (مثل: Update index.html).

اضغط على زر Commit changes الأخضر.

انتظر دقيقة واحدة، ثم قم بتحديث رابط موقعك وستظهر التعديلات الجديدة فوراً.

الطريقة الثانية: باستخدام برنامج VS Code (إذا كنت تعمل من جهازك محلياً)
إذا كنت تستخدم محرر الكود على جهازك، افتح Terminal (طرفية الأوامر) داخل مجلد المشروع ونفذ الأوامر الثلاثة التالية بالترتيب:

إضافة الملفات المعدلة:

Bash
git add .
حفظ التعديلات برسالة وصفية:

Bash
git commit -m "update site code"
رفع التعديلات إلى جيت هب:

Bash
git push origin main
بعد تنفيذ هذه الأوامر، سيقوم جيت هب بتحديث الموقع تلقائياً خلال دقيقة واحدة! أخبرني أي طريقة تستخدم لو واجهتك أي خطوة.

PS E:\مجلد جديد\citimarketn> git commit -m "update site code"

[main 71bf3ca] update site code

 2 files changed, 939 insertions(+), 195 deletions(-)

 create mode 160000 citimarketn

PS E:\مجلد جديد\citimarketn> git push origin main

To https://github.com/citimarketn/citimarketn.git

 ! [rejected]        main -> main (non-fast-forward)

error: failed to push some refs to 'https://github.com/citimarketn/citimarketn.git'

hint: Updates were rejected because the tip of your current branch is behind

hint: its remote counterpart. If you want to integrate the remote changes,

hint: use 'git pull' before pushing again.

خطأ non-fast-forward يعني أن النسخة الموجودة على موقع GitHub تحتوي على تعديلات غير موجودة في جهازك حالياً (أو حدث تعارض في الإصدارات)، ولحل هذه المشكلة دمج التعديلات ورفعها بنجاح، نفذ الأمر التالي في التيرمينال:

Bash
git pull origin main --rebase
بعد تنفيذ هذا الأمر، إذا ظهرت لك أي نافذة أو توقف، اكتب الأمر التالي لرفع التعديلات فوراً:

Bash
git push origin main
وبهذا سيتم دمج التعديلات ورفع النسخة الجديدة مباشرة لتظهر على موقعك!
